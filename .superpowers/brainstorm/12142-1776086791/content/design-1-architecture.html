节点体系设计

5 种核心节点类型，覆盖完整 Agent 工作流

入

用户输入节点 (Start)

工作流入口。接收用户文本输入，写入 LangGraph State，触发图执行。

🧠

大模型节点 (LLM)

通过 LangChain ChatModel 调用 LLM。可配置：模型选择、Temperature、System Prompt、流式输出。支持 OpenAI / Anthropic / Google 等。

📚

RAG 知识检索节点

完整 RAG 链路：文本 → Embedding → 向量检索 (Chroma) → Reranking → 注入上下文。可配置：知识库选择、Top-K、相似度阈值。

🎙

TTS 音频合成节点

LangChain Tool 封装。接收文本，调用 TTS 服务生成音频。抽象接口设计，支持多 Provider 切换。输出音频 URL。

🤖

Agent 节点 (ReAct)

LangGraph ReAct Agent。LLM 自主推理，决定调用哪些 Tool（RAG 检索、TTS 合成等）。面试核心亮点：展示 Agent 自主决策能力。

⏹

结束节点 (End)

工作流终点。汇总所有节点输出（文本 + 音频），返回最终结果给前端调试面板。
