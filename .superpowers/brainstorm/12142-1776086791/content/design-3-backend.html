2
Graph Compiler 编译为 LangGraph
# graph_compiler.py

class GraphCompiler:
  def compile(self, workflow_def) -> StateGraph:
    # 1. 验证 DAG（环检测）
    # 2. 拓扑排序确定执行顺序
    # 3. 为每个节点创建 LangGraph node function
    # 4. 根据 edges 添加 LangGraph edges
    # 5. 返回编译好的 StateGraph

    graph = StateGraph(WorkflowState)
    for node in workflow_def.nodes:
      handler = NodeRegistry.get(node.type)
      graph.add_node(node.id, handler.execute)
    for edge in workflow_def.edges:
      graph.add_edge(edge.source, edge.target)
    return graph.compile()
3
LangGraph State 在节点间流转
class WorkflowState(TypedDict):
  input: str             # 用户原始输入
  messages: list[BaseMessage] # LLM 对话历史
  context: str           # RAG 检索的上下文
  llm_output: str        # LLM 生成的文本
  audio_url: str         # TTS 生成的音频 URL
  node_outputs: dict      # 各节点输出快照

状态流转:
Start → state.input = "AI 教育播客"
LLM   → state.llm_output = "大家好，欢迎收听..."
TTS   → state.audio_url = "/audio/xxx.mp3"
End   → 返回 state 给前端
4
SSE 实时推送节点状态
GET /api/workflows/{id}/runs/{run_id}/events
Content-Type: text/event-stream

event: node_start   // { node_id: "llm_1", status: "running" }
event: node_stream  // { node_id: "llm_1", chunk: "大家好，" } ← LLM 流式
event: node_stream  // { node_id: "llm_1", chunk: "欢迎收听..." }
event: node_end    // { node_id: "llm_1", status: "completed", duration: 3.2 }
event: node_start   // { node_id: "tts_1", status: "running" }
event: node_end    // { node_id: "tts_1", output: { audio_url: "/audio/xxx.mp3" } }
event: workflow_end // { status: "completed", duration: 8.5 }
